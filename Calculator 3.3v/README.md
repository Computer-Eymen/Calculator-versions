Calculator v3.3 is more than just a calculator; it's a pure C-based computing engine designed to minimize unnecessary software bloatware and maximize hardware efficiency. In a world overflowing with complex software, this project returns to the roots of programming—Logic, Stability, and Control.

🚀 Engineering Features

Zero-Bloat Philosophy: Built from scratch using 100% pure C. No unnecessary overhead, just optimized performance.

Input Integrity: Advanced scanf filtering prevents crashes caused by non-numeric inputs. The system enforces valid data types to maintain the runtime environment.

Division by Zero Protection: The division module includes an active safety mechanism that neutralizes division by zero attempts in real time, preventing system instability.

Continuous Logic Loop: Designed for high-frequency operations, the system uses a robust do-while loop mechanism to ensure continuous operation without the need to reload the binary file. (NOTE: The assembly code for these systems will now also be published; anyone interested can open and view it.)

⚙️ Computational Capabilities

Arithmetic Core: Standard operations (Addition, Subtraction, Multiplication, Division, Module/Remainder).

Geometry Package: Specialized modules for area/perimeter calculations of triangles, squares, and rectangles.

Data Processing: Arithmetic mean calculation (supports dynamic sets of 2 to 5 inputs).

Mathematical Foundations: Directly coded math.h integration for square root and exponentiation modules.

Operations involving the number pi are also included in this version.

🛠️ Distribution and Compilation

For those who want to interact with the raw logic:
Linux (Native Distribution)

Dependencies:
Bash

sudo apt update && sudo apt install build-essential

Compilation:
Bash

gcc main.c -o calculator

Execution:
Bash

./calculator

Windows (GCC/MinGW)

Use your preferred compiler environment for compilation:
Bash

gcc main.c -o ComputerEymen_v3.3.exe

Launch the resulting executable (binary) directly.
