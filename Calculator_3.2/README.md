🐧 Running and Compiling on Linux

No installation is required to run the project on Linux operating systems (Debian, Ubuntu, Arch, etc.); you can use it by compiling directly from the source code:

1. Installing Required Tools
If the gcc compiler is not installed on your system, you can install it by entering the following command in the terminal:

sudo apt update && sudo apt install build-essential

2. Compiling from Source Code
Open the terminal inside the Calculator_3.2v folder and enter the following command:

gcc Calculator_3.2v.c -o calculator

3. Running
Once the compilation process is complete, you can run the program with the following command:


./calculator

Note: If you wish to grant execution permissions to the file, you can use the command `chmod +x calculator`.
